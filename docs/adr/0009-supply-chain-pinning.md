# ADR-0009: Pin every image by digest

Status: Accepted

## Context

Floating tags like `grafana/grafana:latest` are tempting, but a lab that changes under you cannot be reproduced, and a silent image change is a supply chain risk.

## Decision

- Every third-party image in `compose.yaml` is pinned as `tag@sha256:digest`.
- Prometheus stays on the LTS line. Versions are chosen from vendor releases checked at build time.
- Renovate is planned to propose digest bumps weekly. Each bump must pass the smoke test before merge.
- Our own images are built from Dockerfiles with pinned bases, run as non-root where the application allows, and are scanned with Trivy in CI.
- Secrets are generated by `scripts/bootstrap.sh` into `.env` (mode 600). There are no default credentials. gitleaks runs in `make lint`.

## Consequences

- Updates are explicit and reviewable.
- Digests go stale. Without Renovate or a manual pass, pins rot and images accumulate known vulnerabilities.

## Alternatives considered

- `:latest` or floating minor tags: what the old repo did.
- Tags without digests: tags can be moved.
