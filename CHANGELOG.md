# Changelog

All notable changes are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

First release of edge-to-trace.

### Added

- Docker Compose `lite` profile with two networks (`app`, `obs`), shared hardening, memory limits and a `tools` profile with a `toolbox` helper.
- Demo app "Acme Books": `storefront` (Elixir/Phoenix), `recs` (Python/FastAPI), `catalog` (Go), Postgres and a k6 load generator at 5 requests per second.
- Telemetry: OpenTelemetry Collector (spanmetrics, servicegraph, tail sampling), Grafana Beyla for `catalog`, Grafana Alloy for logs, Tempo 3, Loki, Prometheus with OTLP receiver and exemplar storage, postgres_exporter.
- Two SLOs on `storefront` (availability 99.5%, latency 99% under 300 ms) with multi-window multi-burn-rate alerts generated by Sloth.
- Compact Telegram message: severity icon, SLO, burn rate, remaining budget (never negative), start time with duration and Dashboard, Traces and Runbook links. Synthetic smoke alerts are routed to the sink only.
- Platform alerts: Watchdog, TargetDown, PrometheusRuleEvaluationFailures, AlertmanagerNotificationsFailing, OtelCollectorExportFailures, LokiIngestionFailing, PostgresDown.
- Alertmanager routing to `alert-sink`, with an optional Telegram override that is used only when the secret files exist.
- Grafana with provisioned datasources and correlation links (metric to trace, trace to logs, logs to trace, service map), and four dashboards: platform overview, SLO detail, service drill-down, Beyla.
- Chaos scenario: `make chaos-latency`, `make chaos-errors`, `make chaos-reset`, and `make demo` / `make demo-reset`.
- Make targets: `up`, `down`, `clean`, `doctor`, `logs`, `ps`, `test`, `lint`, `smoke`, `slo`.
- Tests: app unit tests, `promtool test rules` for platform and SLO rules, Alertmanager route tests, API-level smoke test.
- Docs: README, ten ADRs, a runbook per alert, SLO, architecture, sizing and troubleshooting pages, SECURITY and CONTRIBUTING.
- CI workflows for lint and app builds.

### Security

- Ports bound to `127.0.0.1`, generated secrets, digest-pinned images, `no-new-privileges`, dropped capabilities, read-only root filesystems where possible, read-only Docker socket proxy.

### Not yet available

Edge (v0.2), SIEM (v0.3) and Kubernetes (v0.4) are planned. macOS Docker Desktop sizing numbers are pending.
